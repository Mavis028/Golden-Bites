# Golden Bites — جولدن بايتس

Animated one-page website for **Golden Bites**, a Cairo caterer of mini bites for weddings and events (mini burgers, mini pizza, hot dogs, crispy chicken sandwiches, pastries and ribbon-tied guest boxes).

## Features
- Arabic, right-to-left, mobile-friendly
- Animated hero with floating food cut-outs, gold shine headline and scroll reveals
- Menu cards with "add to order" buttons
- Online order form that sends the full order to WhatsApp (01026748725)
- Photo gallery

## Files
- `index.html` — the whole site (HTML, CSS and JS in one file)
- `img/` — photos and cut-out images

## Run locally
Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```
